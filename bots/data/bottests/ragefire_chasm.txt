# The scripted runs of Ragefire Chasm (spec section 10). The format is in
# src/bots/RunScript.h. Start a run over SOAP:
#   .wowai run start ragefire_chasm <scenario>
#   .wowai run status
# Each run starts from a full reset of the test driver and the four bots.
# The points and packs are those of routes/ragefire_chasm.txt. Each run
# writes a result file (and a trace when it fails) to the folder runs/ of
# the mangosd logs. wowai/test-realm/runs.py starts runs and collects them.
script ragefire_chasm ragefire_chasm
driver Ezzra
group Grukk Hela Shanka Morzul
outside 1 1811.78 -4410.50 -18.47   # the entrance in Orgrimmar (game_tele 46)

# Full run: the whole dungeon, step by step along the route. It passes when
# the fourth boss dies (spec section 10).
# The talk of spec section 10: the test driver whispers each bot once and
# writes once in party chat. Each whisper gets an answer of its bot, and the
# party message 1 or 2 answers (wowai/test-realm/runs.py checks them).
scenario full
teleport p1
command follow
wait 20                 # the buffs
whisper Grukk how are you holding up?
whisper Hela how are you holding up?
whisper Shanka how are you holding up?
whisper Morzul how are you holding up?
command good luck in there, everyone
route

# Boss scenario: the group starts at Taragaman the Hungerer and runs only
# that fight.
scenario taragaman
teleport pull_taragaman_the_hungerer
clear 60                # the trash of his room goes away
command follow
wait 20                 # the buffs: Fortitude, Inner Fire, Demon Skin, Imp
command stay
refill                  # full health and mana after the buffs
wait 3                  # a bot that drank stands up: the group rests no more
target 11520
command pull
wait combat_end 300
expect boss_dead 11520

# Adds that join a fight in its middle (a "name pull"): the group pulls a
# pack of one mob, and 12 s later, when the tank holds it, a `join`
# sends a second pack in from where it stands. The tank must pick up the
# adds, the healer must live, and the damage bots must not lose the plot.
# The result lists the second pack as an extra pack of the pull that the
# script brought (not the tank's fault); the threat losses, the deaths, and
# the fight summary show how the group took it.
#
# One Ragefire Trogg (pack13), then a Ragefire Shaman and two Troggs
# (pack14, 29.7 yd from pack13, about 45 yd from the pull point) on the
# member nearest to them.
scenario join_three
expect healer_threat_losses 0  # per pull, through the whole run (jvbastel/WOWAI#165)
expect healer_pickup_seconds 6        # an extra-pack enemy on the healer is on the tank in 6 s (#168)
expect threat_targets_without_cast 0  # the tank casts on each threat target it turns to (#168)
expect damage_chase_yards 25  # no damage bot chases farther from the tank (jvbastel/WOWAI#171)
teleport p18             # 23 yd from pack13: pull_pack13 is in its aggro reach
clear 100 pack13 pack14  # only the two packs stay; also the patrol pack7
command follow
wait 20
command stay
refill
wait 3
target pack13
command pull
wait 12
join pack14
wait combat_end 300
expect pack_dead pack13
expect pack_dead pack14
expect alive
