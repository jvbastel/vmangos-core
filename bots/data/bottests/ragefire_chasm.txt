# The scripted runs of Ragefire Chasm (spec section 10). The format is in
# src/bots/RunScript.h. Start a run over SOAP:
#   .wowai run start ragefire_chasm <scenario>
#   .wowai run status
# Each run starts from a full reset of the test driver and the four bots.
# The points and packs are those of routes/ragefire_chasm.txt. Each run
# writes a result file (and a trace when it fails) to the folder runs/ of
# the mangosd logs. wowai/test-realm/runs.py starts runs and collects them.
script ragefire_chasm ragefire_chasm
driver Ezzra
group Grukk Hela Shanka Morzul
outside 1 1811.78 -4410.50 -18.47   # the entrance in Orgrimmar (game_tele 46)

# Full run: the whole dungeon, step by step along the route. It passes when
# the fourth boss dies (spec section 10).
# The talk of spec section 10: the test driver whispers each bot once and
# writes once in party chat. Each whisper gets an answer of its bot, and the
# party message 1 or 2 answers (wowai/test-realm/runs.py checks them).
scenario full
teleport p1
command follow
wait 20                 # the buffs
whisper Grukk how are you holding up?
whisper Hela how are you holding up?
whisper Shanka how are you holding up?
whisper Morzul how are you holding up?
command good luck in there, everyone
route

# A full run without the steps that are only there for a quest.

# Boss scenario: the group starts at Taragaman the Hungerer and runs only
# that fight.
scenario taragaman
teleport pull_taragaman_the_hungerer
clear 60                # the trash of his room goes away
command follow
wait 20                 # the buffs: Fortitude, Inner Fire, Demon Skin, Imp
command stay
refill                  # full health and mana after the buffs
wait 3                  # a bot that drank stands up: the group rests no more
target 11520
command pull
wait combat_end 300
expect boss_dead 11520

# Trash scenario: the group runs one fixed pack, two Searing Blade

# A short run that passes, for the check t82_run_group.py: after it, the
# members are out of the run group (jvbastel/WOWAI#82).
scenario short
teleport pull_pack37
clear 50
wait 2
expect alive

# Full-run pacing of jvbastel/WOWAI#94: the check t94_pacing.py kills the
# whole group in the fight. The pack lives after it: the group revives at
# the entrance, walks back, rests until full, and fights the pack again.
scenario refight
teleport p2
clear 40 pack1          # only the pack stays
command follow
wait 20
move pull_pack1
wait arrive
refill
wait rested             # no settle: the coordinator sees a rest at once
command stay
fight pack1
command follow

# Two-pack scenario of jvbastel/WOWAI#103: two standing packs 9.5 yd apart,
# one Searing Blade Enforcer each. The group fights pack48 at its own place,
# so pack49 is expected to join. The result lists it as an extra pack of the
# pull (pulls[].extra_packs); the run does not fail on it.
scenario two_packs
teleport pull_pack48
clear 50 pack48 pack49  # only the two packs stay
command follow
wait 20
command stay
refill
wait 3
fight pack48
expect pack_dead pack48

# Two packs apart, for the fight spot of jvbastel/WOWAI#105: pack52 and
# pack54, one standing Searing Blade Cultist each, 11.9 yd apart (more than

# The tank holds pack52 at a fight spot on that trail where pack54 does
